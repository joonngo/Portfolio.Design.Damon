# Thêm dự án qua CMS

**Tạo token (một lần, làm lại khi hết hạn)**
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: chỉ chọn `Portfolio.Design.Damon`. Permissions → Contents: Read and write. Đặt ngày hết hạn.
3. Copy token, cất trong trình quản lý mật khẩu. Không gửi cho ai, không đưa vào repo.

**Đăng nhập:** mở `https://joonngo.github.io/Portfolio.Design.Damon/admin/`, chọn Sign In Using Access Token, dán token.

**Thêm dự án:** Projects → New. Tắt "Selected" nếu thuộc Archive. Để "Nháp" bật tới khi sẵn sàng. Ảnh tối đa 5MB, nên rộng từ 1600px. Ô nào để trống, site ghi "To be updated". Lưu xong, site tự cập nhật sau vài phút.
